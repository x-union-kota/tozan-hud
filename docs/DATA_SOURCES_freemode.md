# DATA_SOURCES 追補 — フリーモード(その場モード)の参照元

ルートを持たないモードでは「回廊先読み」も「OSMベクタ焼き込み」も使えない。
以下をフリーモードの参照元として**固定**する。すべて地理院タイル(出典明示のみで利用可)、
ホストは既存 sw.js のキャッシュ対象 `cyberjapandata.gsi.go.jp`。

## 1. 地形(等高線用): 標高タイル PNG

| 用途 | URL | ズーム | メッシュ | 取得タイミング |
|---|---|---|---|---|
| 10km四方の概観 | `https://cyberjapandata.gsi.go.jp/xyz/dem_png/{z}/{x}/{y}.png` | **z14** | 10m | 初回測位直後に一括(約36枚) |
| 中心2km四方の詳細 | `https://cyberjapandata.gsi.go.jp/xyz/dem5a_png/{z}/{x}/{y}.png` | **z15** | 5m(航空レーザ) | 遅延。404なら下の代替へ |
| dem5a欠損域の代替 | `https://cyberjapandata.gsi.go.jp/xyz/dem5b_png/{z}/{x}/{y}.png` → `dem5c_png` → z14の`dem_png` | z15 | 5m(写真測量) | dem5aが404のときのみ |

デコード(全PNG共通): ピクセル(R,G,B)で `x = R*65536 + G*256 + B`。
`x < 2^23` → 標高 = x×0.01m / `x = 2^23` → 無効 / `x > 2^23` → (x − 2^24)×0.01m。無効値は (128,0,0)。
canvasに `crossOrigin='anonymous'` で不透明描画→getImageData。

タイル座標: 標準Webメルカトル(`x = floor((lon+180)/360·2^z)`, `y = floor((1 − ln(tan φ + sec φ)/π)/2·2^z)`)。
10km四方 = 中心タイルから z14 で ±3 タイル(1タイル≈2km@北緯36°)。

提供範囲チェック: 緯度20〜46・経度122〜154の外では取得しない(「地形データ提供範囲外」表示)。

## 2. 街中用の下地(フリーモードのみ許可): 淡色地図ラスタ

| 用途 | URL | ズーム | 後処理 |
|---|---|---|---|
| 位置把握の下地 | `https://cyberjapandata.gsi.go.jp/xyz/pale/{z}/{x}/{y}.png` | **z15**(概観)/ **z16**(詳細) | 反転→2値化(閾値: 反転後の輝度 > 0.55 を線として `#4a463e` で描画、それ以外は透明) |

淡色地図(pale)を選ぶ理由: 標準地図(std)より地色が薄く配色が少ないので、反転+2値化で道路・水涯線・鉄道が
グレーの線画として素直に抜ける。標準地図は反転すると面の色が残って加算ディスプレイで「モヤ」になる。
2値化後の線は最暗グレーに固定し、ルート/現在地(黄)より必ず暗くする(明度階層を守る)。

適用条件: フリーモード かつ 等高線の自動間隔判定で「平坦地(標高差<3m)」または画面内標高レンジ<15m のとき。
山域では使わない(等高線と競合して読めなくなる)。ルート有りモードでは従来通り使わない。

## 3. 表示ロジックの優先順(フリーモード)

1. 測位なし → 「測位待ち」
2. 日本範囲外 → 「地形データ提供範囲外」
3. 取得中 → `地形 12/36 取得中`
4. 標高レンジ ≥ 15m → 等高線(自動間隔。8〜20本になるよう 1/2/5/10/20/50/100m から選択、計曲線=主曲線×5)
5. 標高レンジ < 15m → 淡色地図の2値化下地 + 「平坦地(標高差○m)」の1行

## 4. クレジット
等高線表示時「地図: 地理院タイル(標高)」、淡色下地時「地図: 地理院タイル(淡色地図)」。両方なら併記。

## 5. 診断画面に追加する項目
現在ズーム / 取得済みタイル数÷必要枚数 / 画面内標高レンジ(m) / 採用等高線間隔 / 下地の有無

## 実装メモ(2026-09-06、v3.2)

- §1 の代替連鎖は `app.js loadDemAny()`: z15 は dem5a → dem5b → dem5c、全滅なら z14 の dem_png から該当四分区画を拡大。
  出典ごとの枚数は診断行に出る。10km 概観の先読みは `prefetchFreeTiles()`(初回測位直後、z14 を中心から
  外側へ最大36枚、SW の TILES キャッシュへ)。提供範囲外(`CORE.inJapanDem`)は取りに行かず「地形データ提供範囲外」
- §2 の 2値化は **反転輝度の閾値では実タイルで文字と記号しか残らなかった**(淡色地図は地色 0.9 前後・道路は白なので、
  反転後 0.55 を超えるのは黒い文字と駅記号だけ。東京駅で実測)。`CORE.paleEdges()` で隣接画素との輝度差 > 0.12 を
  線として `#4a463e` に落とす方式に変更。道路は縁が2本線で出るが線画として読める。文字の輪郭は残る(許容)
- §3 の優先順は `panelMap()` のフリーモード分岐そのまま。平坦の閾値は「画面内レンジ < 15m」(3m 判定は包含)。
  平坦地の注記「平坦地(標高差○m)」はクレジットに並べると1行に収まらずスケールバーに重なるので、
  走行キャプション側に出す。等高線の自動間隔は `CORE.freeContourStep`(20本以内に収まる最小の間隔、計曲線=×5)。
  ルート有りモードの等高線(10/50m 固定・平坦 <10m)は変えていない
- §5 は `diagHtml()` の末尾行: `地形: z15 タイル 4/4 (dem5a_png 3, dem_png@14 1) レンジ32m 等高線2/10m 下地無`
- テスト: core `[free terrain]`(間隔・2値化・提供範囲)、smoke(取得中/測位待ち/提供範囲外の優先順)。
  タイルの実描画は jsdom では出来ないので、東京駅(平坦→淡色下地)をブラウザで目視した
